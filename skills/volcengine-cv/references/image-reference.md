# 即梦图像生成 API 参考文档

## 1. 接口介绍

即梦4.0是即梦同源的图像生成能力，该能力在统一框架内集成了文生图、图像编辑及多图组合生成的功能。支持单次输入最多 10 张图像及进行复合编辑，并能通过对提示词的深度推理，自动适配最优的图像比例尺寸与生成数量，可一次性输出最多 15 张内容关联的图像。

### 主要特性

- **多图输入输出**：支持多图输入（0-10张），支持多图（组图）输出（最多15张）
- **智能比例适配**：根据提示词自动推理最优的图像比例和生成数量
- **中文优化**：显著提升中文生成的准确率与内容多样性
- **4K超高清**：支持 4K 超高清输出，为专业图像创作提供完整解决方案

---

## 2. 核心能力

### 2.1 多图输入输出

- **多图输入**：一次性输入多张图像，支持组合、迁移、替换、衍生等复合编辑
- **多图组合输出**：一次性输出多张内容关联的图像，做创意脑暴/分镜创作的好帮手

### 2.2 深度理解意图

- **意图理解**：简单语言描述需求即可准确完成增删、修改、替换、参考等编辑效果
- **交互可控**：支持框选图片任意区域进行定向修改，提升创意自由度和操作可控性

### 2.3 商用可控

- **文字准确性**：针对文字生成的准确率优化，小字准确率极高，文字重复问题得到极大改善
- **人像美化**：可高效完成人像修图，最大化保留原图细节
- **超高清输出**：支持最高4K分辨率生成

## 4. 提示词建议

### 文生图提示词

**基本原则：**
- 用**连贯的自然语言**描述**画面内容**（主体+行为+环境等）
- 用**短词语**描述**画面美学**（风格、色彩、光影、构图等）

**高阶技巧：**
1. **组图生成**：使用"一系列""组图""帮我生成几张图"等提示词触发组图，最多支持生成10张
2. **比例指定**：可在提示词中直接输入比例指令，模型会自动推理最优比例
3. **文字准确率**：把想要生成的文字内容插入""引号中，例如"标题为\"Seedream V4.0\""
4. **专业词汇**：使用词源语言的专业词汇，效果更准确
5. **场景适配**：明确指出图像用途和类型，例如"用于PPT封面背景"

### 图像编辑提示词

**基本公式：**变化动作 + 变化对象 + 变化特征

**示例：**
- "将骑士的头盔变为金色"
- "把人物的衣服改为黑色"

**最佳实践：**
- 使用**清晰明确**的指令
- 使用参考图保持一致性
- 使用精确的风格词或直接输入风格参考
- 明确指出不同图片需参考/编辑的不同元素

## 5. API 使用限制

### 输入要求

| 限制项 | 详细说明 |
|-------|--------|
| **图片格式** | 仅支持JPEG、PNG格式，建议使用JPEG |
| **文件大小** | 最大 15MB |
| **输入图数量** | 最多 10 张 |
| **分辨率** | 最大 4096 × 4096 |
| **宽高比** | （宽/高）范围：[1/3, 3] |

### 输出说明

| 限制项 | 详细说明 |
|-------|--------|
| **输出图数量** | 最大输出图数量 = 15 - 输入图数量 |
| **输出格式** | PNG 格式 |
| **链接有效期** | 24 小时 |

### 性能建议

- 输出分辨率越大、输出图数量越多、输入图数量越多，延迟增加越明显
- 1次调用可能输出多张图片，根据输出图片张数进行计费
- 对延迟&价格敏感时，建议使用 `force_single` 参数强制只输出1张图片
- 输入图片建议控制在6张以内，图片过多会降低参考效果
- 建议生成 2K 以上的图片，过小分辨率容易出现人脸效果不佳、文字异常等问题

## 6. API 接入指南

### 6.1 请求信息

| 项目 | 内容 |
|------|------|
| **接口地址** | https://visual.volcengineapi.com |
| **请求方式** | POST |
| **Content-Type** | application/json |
| **Region** | cn-north-1（固定值） |
| **Service** | cv（固定值） |

### 6.2 提交任务

#### Query 参数

| 参数 | 类型 | 必选 | 说明 |
|------|------|------|------|
| Action | string | 是 | 接口名，取值：**CVSync2AsyncSubmitTask** |
| Version | string | 是 | 版本号，取值：**2022-08-31** |

#### Body 参数

| 参数名 | 类型 | 必选 | 说明 |
|-------|------|------|------|
| req_key | string | 是 | 服务标识，取固定值：**jimeng_t2i_v40** |
| image_urls | array of string | 否 | 图片文件 URL，**支持输入 0-10 张图**。图片数量越多、图片尺寸越大，整体服务处理时间越长。**输入图片建议控制在 6 张以内，图片过多会降低参考效果** |
| prompt | string | 是 | 用于生成图像的提示词，中英文均可输入。**建议最长不超过 800 字符，prompt 过长有概率出图异常或不生效**。支持通过 prompt 中直接指定生图比例，模型会根据"size"字段智能判断生图宽高比，默认生成 2K 分辨率、宽高比不超过 3 的图像。**除""外不建议输入特殊的符号如 $** |
| size | int | 否 | **生成图片的面积**，默认值：4194304，即 2048×2048，生成 2K 分辨率图像<br/>**【文生图场景】**<br/>• 取值范围：[1024×1024, 4096×4096]，可生成 1K 到 4K 分辨率图像<br/>• 面积和宽高需要 2 选 1 传入，都不传则默认面积取"2048×2048"，即生成 2K 分辨率图像且模型智能判断宽高比<br/>• **建议生成 2K 以上的图片，过小分辨率图片较大概率出现人脸效果不佳、文字异常等效果问题；若 2K 图片出图效果也不符合预期，可尝试输出更高分辨率图片**<br/>• 面积和宽高同时输入时，优先使用宽高<br/>• 只传面积，模型会根据用户 prompt 意图智能判断生图宽高比<br/>**【图生图场景】**<br/>• 结合用户 prompt 意图、参考图尺寸，由模型智能判断生图宽高比 |
| width | int | 否 | **生成图像宽高**，默认该字段不传<br/>• 宽高乘积在 [1024×1024, 4096×4096]，且宽高比在 [min_ratio, max_ratio] 之间<br/>• **需同时传 width 和 height 才会生效** |
| height | int | 否 | **生成图像高度**<br/>• 需同时传 width 和 height 才会生效 |
| scale | float | 否 | 文本描述影响的程度，范围 [0, 1]，默认值：0.5。越大代表文本影响程度越大，输入图片影响程度越小（精度：支持小数点后两位） |
| force_single | bool | 否 | 是否强制生成单图，默认值：false。**注意：生成的组图越多，耗时越久，且生成耗时会随图片数量增多而显著变长；如需稳定的组图输出效果，建议 prompt 控制组图数量在 9 张及以内；生成组图时，建议 prompt 明确指明图片分辨率或直接传参具体宽高值，避免模型生成组图分辨率不一致导致接口报错** |
| min_ratio | float | 否 | 生图结果的宽/高 ≥ min_ratio，如果智能选比例 < min_ratio，则用 min_ratio。默认值：1/3，取值范围：[1/16, 16) |
| max_ratio | float | 否 | 生图结果的宽/高 ≤ max_ratio，如果智能选比例 > max_ratio，则用 max_ratio。默认值：3，取值范围：[1/16, 16) |

#### 推荐的宽高尺寸

**1K 分辨率：**
- 1024×1024（1:1）

**2K 分辨率：**
- 2048×2048（1:1）
- 2304×1728（4:3）
- 2496×1664（3:2）
- 2560×1440（16:9）
- 3024×1296（21:9）

**4K 分辨率：**
- 4096×4096（1:1）
- 4694×3520（4:3）
- 4992×3328（3:2）
- 5404×3040（16:9）
- 6198×2656（21:9）

### 6.3 查询任务

#### Query 参数

| 参数 | 类型 | 必选 | 说明 |

| Action | string | 是 | 接口名，固定值：**CVSync2AsyncGetResult** |

#### Body 参数

| 参数名 | 类型 | 必选 | 说明 |

#### 水印配置（LogoInfo）

| 参数 | 类型 | 说明 |

#### 请求示例

## 8. 常见问题

### 数据链接相关

**Q: 返回的图片链接有效期是多久？**

A: 图片链接的有效期为 24 小时，超过 24 小时后需要重新生成。

**Q: 返回的资源地址域名有哪些？**

A: 资源地址的域名包括：
- v3-vvecloud.yangyi08.com
- v6-vvecloud.yangyi08.com
- v9-vvecloud.yangyi08.com
- v26-vvecloud.yangyi08.com

### 任务相关

**Q: 提交任务接口返回的 taskID 有效期是多久？**

A: taskID 的有效期为 24 小时，超过 24 小时后无法获取结果。

**Q: 如何取消异步调用接口？**

A: 调用 CVCancelTask 接口，注意当前不支持取消 generating 状态的任务。

请求示例：
```json
{
    "req_key": "接口服务req_key",
    "task_id": "<任务task_id>"
}
```
